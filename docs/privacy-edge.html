English summary
本地生成光效，不上传观看内容

Ambient light for Bilibili 在本机临时处理当前播放的视频画面，生成外围光效，并在你主动开启宽屏去边时分析边框。扩展不将视频帧、页面地址或设置传给开发者或第三方。

处理的信息与用途

  • 视频画面：在本机绘制低分辨率画布以生成氛围光；开启去边时读取低分辨率像素以判断稳定边框。
  • 当前播放页路径与播放器状态：用于判断是否在支持的页面、定位播放器、适配播放模式和恢复页面样式，不建立观看历史记录。
  • 用户设置与同意状态：将开关、预设、光效参数、去边选项及是否接受本地处理的状态保存在 chrome.storage.local，供同一浏览器配置内的扩展入口使用。

保存期限与共享

视频画面和边框分析仅供当前页面功能使用，不保存为视频文件。暂停时可能在页面内存保留当前光色；关闭页面后不保留该页面的画面缓存。显示参数与同意状态保存在本机；你可重置参数、撤回同意，或通过卸载扩展清除本地存储。本扩展不使用浏览器云同步保存设置，也没有开发者服务器副本。

扩展不读取 Cookie、账号密码或支付信息，不添加遥测、统计、广告或追踪服务。不会出售、分享或转交本地处理的观看内容给开发者或第三方。

权限与用户选择

storage 权限用于保存本地设置。内容脚本范围为 https://www.bilibili.com/*，0.5.3.2 直播预览版新增 https://live.bilibili.com/*，以支持站内单页跳转；光效针对 /video/、/bangumi/play/ 路径，以及 0.5.3.3 新增的 /list/watchlater/ 详情播放路径，以及直播站的数字房间路径（0.5.3.5 起同时支持 /blanc/数字房间号）。

首次使用 0.5.1 或从旧版升级后，在你阅读界面说明并选择“同意并开启”前，不采样视频或生成光效。你可以随时关闭光效，或在设置中撤回同意并停用；卸载扩展会由浏览器移除扩展本地存储。“恢复默认”用于重置显示参数，不等于删除全部本地数据。

English summary

Publisher: TXIM301. Contact: txim301@outlook.com. Updated October 8, 2026. Applies to versions 0.5.1–0.5.3.15.

The extension processes the current Bilibili video locally to render ambient light. Optional border removal analyzes low-resolution pixels. The current playback route and player state are used only to activate and position these features. Content scripts run on www.bilibili.com; the 0.5.3.2 live preview also runs on live.bilibili.com, with ambient processing limited to numeric live-room routes. Version 0.5.3.3 adds watch-later detail playback at /list/watchlater/ within the existing www.bilibili.com scope. Version 0.5.3.5 also supports /blanc/ numeric live-room routes within the existing live.bilibili.com scope. Preferences and the consent state are saved in browser-local extension storage.

No video frames, page addresses, viewing history or preferences are uploaded to the publisher or third parties. There are no analytics, ads, trackers or remote code. The extension does not read cookies, passwords or payment details. Frames are transient page-memory data; settings remain locally until reset or removal.

Since version 0.5.1, the extension requires an explicit first-use choice before video sampling. You can disable the light or withdraw consent in settings. Uninstalling removes extension-local storage. Support emails are used to handle your feedback. GitHub Pages may log visitors’ IP addresses for security when this policy website is visited; the website adds no analytics. Any change in data practices will be disclosed and consent obtained where required.
