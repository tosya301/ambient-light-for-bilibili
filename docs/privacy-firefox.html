本地生成光效，不上传观看内容

Ambient light for Bilibili 在本机临时处理当前播放的视频画面，生成外围光效，并在你主动开启宽屏去边时分析边框。扩展不将视频帧、页面地址、观看记录或设置传给开发者或第三方。

处理的信息与用途

  • 视频画面：在本机绘制低分辨率画布以生成氛围光；开启自动去边时读取低分辨率像素以判断稳定边框。
  • 当前播放页路径与播放器状态：用于判断是否在支持的页面、定位播放器、适配播放模式和恢复页面样式，不建立观看历史记录。
  • 用户设置与同意状态：光效开关、预设、显示参数、去边、圆角、阴影、入口显示选项及本地处理的同意状态保存在浏览器的扩展本地存储 storage.local 中，供同一浏览器配置内的扩展入口使用。

保存期限与共享

视频画面和边框分析仅用于当前页面功能，不保存为视频文件。暂停时可能在页面内存保留当前光色；关闭页面后不保留该页面的画面缓存。显示参数与同意状态保存在本机；你可重置参数、撤回同意，或通过卸载扩展清除扩展本地存储。本扩展不使用浏览器云同步保存设置，也没有开发者服务器副本。

扩展不读取 Cookie、账号密码或支付信息，不添加遥测、统计、广告或追踪服务，不运行远程代码。不会出售、分享或转交本地处理的观看内容给开发者或第三方。Firefox 安装界面的“无数据收集”声明表示本扩展不向扩展或本地浏览器以外传输数据；上述视频处理仍在本机进行。

权限与用户选择

storage 权限用于保存本地设置。内容脚本范围为 https://www.bilibili.com/* 与 https://live.bilibili.com/*，以支持站内单页跳转。光效针对桌面端 /video/、/bangumi/play/、/list/watchlater/ 详情播放页，以及直播站的数字房间路径和 /blanc/数字房间号。

首次使用时，在你阅读界面说明并选择同意开启前，不采样视频或生成光效。你可以随时关闭光效，或在“更多”中撤回同意并停用。撤回同意立即停止视频处理并恢复页面，保留显示参数；再次开启需要重新同意。“恢复默认”用于重置显示参数，不等于删除全部本地数据。卸载扩展会由浏览器移除扩展本地存储。

支持邮件与外部服务

如果主动通过 txim301@gmail.com 联系发布者，你发送的邮件将由邮件服务传递，并用于处理反馈。请勿发送密码或不必要的敏感信息。扩展不会自动发送支持邮件或附加诊断数据。

扩展内置的本政策页面可离线查看，不加载外部脚本、字体或图片。若你访问本项目的 GitHub Pages 网站，GitHub 可能为安全目的记录 IP 地址，详见 GitHub Pages 数据说明。项目网站没有额外的分析或广告脚本。你使用 Bilibili、浏览器、商店、GitHub 或邮件服务时，这些服务按其自身政策处理信息。

用途限制与政策更新

本扩展仅将上述信息用于公开说明的氛围光及显示调整功能，不将信息用于广告、出售、用户画像或无关用途。扩展不修改视频地址，不绕过受保护媒体、付费内容或访问限制。若数据处理方式发生改变，将更新政策，并按适用要求显著说明及取得同意。

Privacy policy — English

Applies to Firefox desktop versions 0.5.3.10–0.5.3.14. Updated October 8, 2026.
Publisher: Deperenn. Contact: txim301@gmail.com.

Ambient light for Bilibili processes the current Bilibili video locally to render ambient light. Optional border removal analyzes low-resolution pixels. The playback route and player state are used to activate and position these features; the extension does not create a viewing history.

Preferences and the consent state are saved in browser-local extension storage (storage.local). Video frames and border analysis are transient page-memory data and are not saved as video files. A paused page may retain its current light color in memory; closing the page releases that page's frame cache. Settings remain locally until reset or extension removal. There is no browser cloud sync or developer-side copy.

No video frames, page addresses, viewing history or preferences are uploaded to the publisher or third parties. There are no analytics, ads, trackers or remote code. The extension does not read cookies, passwords or payment details, and does not sell or share the locally processed content. The Firefox “no data collection” declaration means no data is transmitted outside the extension or local browser; the local processing described above still takes place.

The storage permission saves local settings. Content scripts run on www.bilibili.com and live.bilibili.com to support same-site navigation. Ambient processing is limited to supported desktop video, bangumi, watch-later detail playback, numeric live-room and /blanc/ numeric live-room routes.

The extension requires an explicit first-use choice before video sampling. You can turn off the light or withdraw consent under the More tab. Withdrawal stops video processing and restores the page while retaining display preferences; enabling the feature again requires consent. Resetting display preferences does not delete all stored data. Uninstalling removes extension-local storage.

If you choose to email the publisher, your email is transmitted by your email provider and used to handle your feedback. The extension does not automatically send support emails or diagnostic data. The bundled privacy page works offline and loads no external scripts, fonts or images. If you visit the project website on GitHub Pages, GitHub may log visitors' IP addresses for security; the project website adds no analytics or ads. Bilibili, Firefox, the add-on store, GitHub and email services process information under their own policies.

The extension does not change video URLs or bypass protected media, paywalls or access restrictions. Information is used only for the described ambient-light and display features. Changes in data practices will be disclosed and consent obtained where required.
