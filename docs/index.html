AMBIENT LIGHT FOR BILIBILI
项目首页GitHub 源码

让视频色彩延伸到播放器周围

为 Bilibili 桌面播放页面添加实时氛围光，提供柔和、影院、绚彩预设，以及可调节的扩散、柔化与色彩过渡。

视频处理只在你的设备上进行

扩展临时处理当前视频画面以生成光效；主动开启宽屏去边时分析低分辨率像素。设置仅保存在浏览器本地，不上传视频帧、观看记录或设置，不添加统计、遥测或广告。

Firefox 提前体验

下载 Firefox 0.5.6 专用体验包（桌面版 Firefox 140+，包含直播悬停底栏圆角与白线修复，并保留 0.5.5 的弹幕修复；Firefox 原生应用已通过 188/188 项本地生产代码合成检查，未验证签名安装／升级或真实 B 站 Firefox 页面）。解压后在地址栏打开 about:debugging#/runtime/this-firefox，点击「临时载入附加组件」，选择解压目录内的 manifest.json，再刷新 B 站播放页面并开启氛围光。

使用范围

面向桌面端 Bilibili 视频、番剧与稍后再看详情播放路径，支持普通数字直播间和 /blanc/ 原版直播间；不支持移动端或第三方嵌入播放器。宽屏去边默认关闭，复杂边框或浏览器读取限制可能使其保留原画。完整验证范围与已知限制见仓库 README。
