AMBIENT LIGHT FOR BILIBILI
项目首页GitHub 源码

让视频色彩延伸到播放器周围

为 Bilibili 桌面播放页面添加实时氛围光，提供柔和、影院、绚彩预设，以及可调节的扩散、柔化与色彩过渡。

视频处理只在你的设备上进行

扩展临时处理当前视频画面以生成光效；主动开启宽屏去边时分析低分辨率像素。设置仅保存在浏览器本地，不上传视频帧、观看记录或设置，不添加统计、遥测或广告。

发布与支持

GitHub 0.5.3.13 正式版提供源码与安装包，支持点播、稍后再看、普通与 /blanc/ 原版直播间；页面入口为可拖动的圆形小电视，可在「更多」→「页面图标」隐藏；修复视频、番剧、稍后再看和直播网页全屏留白透出顶部头像导航与下方内容的问题，保留普通直播 SC 和下方内容透光。新增可选玻璃控制栏（画面 → 播放器外观，默认关闭），圆角开启后在普通和宽屏都生效，并修复吸底评论栏透出后方文字和图片的问题。0.5.3.13 修复宽屏圆角内部滚动导致的双层边缘，并让章节侧栏和列表底色透光。2026-10-08：正在向 Chrome、Edge 和 Firefox 提交此版更新。安装与验证范围见仓库 README。

Firefox 提前体验

下载 Firefox 0.5.3.13 专用体验包（桌面版 Firefox 140+，包含最新圆角与章节透明修复）。解压后在地址栏打开 about:debugging#/runtime/this-firefox，点击「临时载入附加组件」，选择解压目录内的 manifest.json，再刷新 B 站播放页面并开启氛围光。

未签名临时体验包：完全退出并重启 Firefox 后，需要重新载入。无需自行构建或关闭签名检查；长期安装请等待商店审核与签名完成。后续 GitHub Release 将同时提供 Chromium、Firefox 和匹配源码包。

使用范围

面向桌面端 Bilibili 视频、番剧与稍后再看详情播放路径，支持普通数字直播间和 /blanc/ 原版直播间；不支持移动端或第三方嵌入播放器。宽屏去边默认关闭，复杂边框或浏览器读取限制可能使其保留原画。完整验证范围与已知限制见仓库 README。
