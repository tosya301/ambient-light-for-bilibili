AMBIENT LIGHT FOR BILIBILI
项目首页GitHub 源码

让视频色彩延伸到播放器周围

为 Bilibili 桌面播放页面添加实时氛围光，提供柔和、影院、绚彩预设，以及可调节的扩散、柔化与色彩过渡。

视频处理只在你的设备上进行

扩展临时处理当前视频画面以生成光效；主动开启宽屏去边时分析低分辨率像素。设置仅保存在浏览器本地，不上传视频帧、观看记录或设置，不添加统计、遥测或广告。

发布与支持

GitHub 0.5.3.15 正式版提供 Chromium、Firefox 和匹配源码包。支持点播、稍后再看、普通与 /blanc/ 原版直播间；页面入口为可拖动的圆形小电视，可在「更多」→「页面图标」隐藏。视频处理和设置仍留在本机，不新增权限。

0.5.3.15 修复开启圆角后向下滚动至评论区时页面异常增高、滚动受阻的问题；播放器进入小窗后保持已有页面占位。方形、4:3、3:4 与竖屏视频开启圆角后保持原生尺寸，实际画面四角使用 12px 圆角，周围留白继续透出氛围光；Mac 录屏和 16:10 保留此前适度放大的完整画面与下方按钮区顺延。圆角可与宽屏去边及去边后填充同时使用，关闭时恢复。

保留此前的网页全屏背景、吸底评论栏、玻璃控制栏、圆角边缘和章节透明修复。0.5.3.14 的较高比例播放器占位修复继续保留；存在比例回归的 0.5.3.13 GitHub Release、附件和远程标签已删除，请使用当前版本。

Chrome 与 Firefox 各通过 196 项视频比例与布局检查、60 项小窗滚动检查，101 项 Node 测试通过；Chrome 真实 B 站方形视频的普通／宽屏圆角和滚动已验证。Firefox 本次验证使用生产代码与本地合成视频，签名安装及其他宿主的验证范围见仓库 README 与 QA 记录。商店可安装版本与更新状态以各渠道审核结果为准。

下载：Chrome / Edge 包 · Firefox 临时体验包 · 匹配源码包。Chrome / Edge 包解压后，在扩展管理页通过开发者模式选择「加载已解压的扩展」，再刷新 B 站播放页面。

Firefox 提前体验

下载 Firefox 0.5.3.15 专用体验包（桌面版 Firefox 140+，包含圆角滚动与方形／竖屏尺寸修复）。解压后在地址栏打开 about:debugging#/runtime/this-firefox，点击「临时载入附加组件」，选择解压目录内的 manifest.json，再刷新 B 站播放页面并开启氛围光。

未签名临时体验包：完全退出并重启 Firefox 后，需要重新载入。无需自行构建或关闭签名检查；长期安装请等待商店审核与签名完成。后续 GitHub Release 将同时提供 Chromium、Firefox 和匹配源码包。

使用范围

面向桌面端 Bilibili 视频、番剧与稍后再看详情播放路径，支持普通数字直播间和 /blanc/ 原版直播间；不支持移动端或第三方嵌入播放器。宽屏去边默认关闭，复杂边框或浏览器读取限制可能使其保留原画。完整验证范围与已知限制见仓库 README。
